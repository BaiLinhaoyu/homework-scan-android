# 学生扫码作业提交与成绩统计（Android 版）

由原制作 tkinter 桌面版移植为安卓原生应用（Kotlin）。
改动：扫码枪键盘输入 → **摄像头扫码**（CameraX + ML Kit）；导出文件 → **安卓系统分享**（可直接转发到钉钉/微信/QQ）。

## 功能

- **名单管理**：新建/导入 Excel 名单（xlsx），点击进入，长按删除；列识别规则与原版一致（姓名 / 学号[学校] / 条形码编号 / 学号[班级]）
- **作业统计**：进入**连续扫码模式**，扫一个录一个无需反复点按，顶部实时显示上一位录入的学生（绿色成功 / 红色未找到）；每次扫码立即落盘保存，退出重进可选择"继续上次"或清空重来；点击学生可改为任意状态（待提交/已提交/已提交未完成/…），颜色区分，未交排前面；未交名单、全部状态表一键分享
- **成绩录入**：扫码后弹窗输入成绩，自动按成绩降序排名，显示平均分/最高/最低；成绩表一键分享
- **钉钉成绩导出（Beta）**：选择钉钉模板 xlsx，自动识别表头与科目，多科目可勾选，填充成绩并计算年级总分排名，生成后调起系统分享


## 构建

1. 用 **Android Studio**（Hedgehog 及以上）打开本目录
2. 首次同步会自动补齐 Gradle Wrapper 并下载依赖（ML Kit 模型约几 MB，首次安装应用时下发）
3. 连接手机（需开启开发者模式/USB 调试）点 Run，或 Build > Build APK 生成安装包

要求：**minSdk 26**（Android 8.0+，因 Apache POI 需要），手机需有摄像头，首次扫码会请求摄像头权限。

## 数据

- 名单和记录保存在应用私有目录 `files/data/`（卸载会清除，请及时分享导出）
- 分享出的 Excel 文件先写入 `cache/shared/`，由 FileProvider 授权给接收方应用；系统"清除缓存"会把已导出的 Excel 一并清掉，重要表格请及时转发保存

## 说明

- Excel 读写使用 Apache POI（StAX 实现为 Woodstox）；若构建时报 `Duplicate class` 或 `META-INF` 冲突，在 `app/build.gradle.kts` 的 `packaging.resources.excludes` 中追加报错提示的路径即可
- 条码识别支持常见一维码（Code128/Code39/EAN 等）与二维码，学生用纸质条码、校园卡条码均可
- 国内构建如遇依赖下载失败，可在 `settings.gradle.kts` 中配置阿里云镜像仓库
